# astock UI 重设计施工图（2026-11-27）

> 四 agent 方案交叉汇总（ChatGPT=信息架构+设计系统，DeepSeek=连板天梯+涨停池，Gemini=大盘总览+情绪周期+简报，Grok=龙虎榜+新闻+美股）。落地执行：CodeBuddy（本地，直接改 F:\astock-src）。

## 现状

- Next.js 15 App Router + Tailwind v4 + shadcn/ui + Prisma + SQLite，深色主题。
- **单页应用**：src/app 只有 page.tsx，15 个视图组件全堆在 src/components/lb/（40+ 组件），难怪乱。

## 一、信息架构（ChatGPT）

15 个模块重组为 **6 个一级导航**，左侧固定侧边栏（可折叠）+ 顶部二级 Tab：

| 一级 | 二级模块 | 组织方式 |
|---|---|---|
| 市场 | 大盘总览、量能、异动 | 合并为市场仪表盘 |
| 情绪 | 情绪周期、连板天梯、涨停池 | 合并为情绪分析 |
| 资金 | 龙虎榜、概念板块 | 独立 Tab |
| 个股 | 个股、策略 | 个股详情与策略分析 |
| 资讯 | 新闻、简报 | 合并为资讯中心 |
| 复盘 | 复盘、历史、美股 | 独立页面或 Tab |

交互规范：
- 侧边栏一级导航，顶部 Tab 二级切换；默认进入市场总览。
- 个股详情独立路由，支持代码搜索和跨模块跳转。
- 历史复盘用日期选择器切换，不占一级导航。
- 美股独立为市场切换入口，不混入 A 股指标。

## 二、设计 Token（ChatGPT，全局）

- 背景：页面 #0B0F14 / 侧边栏 #111821 / 卡片 #18222D / 悬浮边框 #243140
- 行情色：涨 #F04452（红）、跌 #00B386（绿）、警告 #E6A23C、主交互 #409EFF
- 圆角：4px 标签 / 6px 按钮 / 10px 卡片
- 字号：12 辅助 / 13 表格 / 14 正文 / 16 模块标题 / 22 页面标题 / 28 核心指标
- 字体 Inter + 思源黑体；**数字一律 tabular-nums**
- 间距 4px 基数，卡片内边距 16px，模块间距 20px
- 原则：高信息密度、低装饰、强对齐；行情数字优先，避免大面积渐变/玻璃拟态/彩色卡片

Gemini 补充：zinc 色系可用（bg-zinc-950 基底、bg-zinc-900/70 border-zinc-800 卡片），红涨 text-rose-500 / 绿跌 text-emerald-500。

## 三、连板天梯 + 涨停池（DeepSeek）

- 顶部 sticky 状态栏（日期、涨停总数、最高板、赚钱效应），下方 Tabs 切「天梯 / 涨停池」。
- 天梯按板数高到低纵向分区，左侧固定阶梯标签（sticky left-0），右侧横向 overflow-x-auto snap-x 卡片列表。
- 涨停池整页表格，表头 sticky top-0 bg-zinc-950/95 backdrop-blur。
- 列优先级：P0 名称/代码、涨停时间、连板数、封单额、概念（≤2 tag + `+N`）；P1（≥lg）换手率、首次封板时间、开板次数；P2 进详情 Sheet（封单/流通市值比、龙虎榜、资金流、历史连板）。行点击开右侧 Sheet。
- 连板高度红色梯度：首板 bg-red-500/15 text-red-400 → 2-3 板 /25 /300 → 4-5 板 /40 /200 → 6 板+ bg-red-600 text-white + ring-red-400。
- 封单强弱按封单额/流通市值：<1% 灰、1-3% amber、>3% red font-semibold，单元格左侧 2px 色条。
- 概念 tag 统一 bg-zinc-800 text-zinc-300，不加彩色。
- 移动端：天梯卡片 w-40 snap-start；涨停池 md 以下切卡片列表（hidden md:table / md:hidden 双渲染）。

## 四、大盘总览 + 情绪周期 + 简报（Gemini）

- 大盘总览：Grid 12 列，顶部 4 张 Card（上证/深证/创业板/两市成交额），下方左 8 列主图（AreaChart 叠分时均线+成交量柱）右 4 列涨跌分布（双色水平堆叠进度条 红/灰/绿）。主指标 text-2xl font-bold，次级涨跌幅 Badge。
- 情绪周期：全宽单卡，顶部状态栏（大号 Badge 标当前周期如「主升期」）+ 核心多折线图（主线 strokeWidth 2.5，X 轴按周期阶段 ReferenceArea 半透明色块分区标注）+ 底部 4 项连板因子小卡（连板高度、晋级率、炸板率、昨日涨停溢价）。
- 每日简报：双栏 max-w-6xl，左 4 列 sticky 关键数据摘要卡（紧凑 Table），右 8 列正文卡；正文结构化排版，「核心主线」「明日策略」用 border-l-2 border-rose-500 pl-3 色条，关键标的代码 bg-zinc-800 font-mono 高亮。

## 五、龙虎榜 + 新闻 + 美股（Grok）

- 统一：背景 bg-zinc-950，卡片 bg-zinc-900 border-zinc-800 rounded-lg，文字 text-zinc-100 / 次要 text-zinc-400，涨红 #f87171 跌绿 #4ade80，数字 tabular-nums。
- 龙虎榜：席位表（日期/上榜原因/营业部买卖），按买卖分组。
- 新闻追踪：垂直时间线（左时间戳 text-dim，右内容），利好/利空徽章 + 标题（一行截断）+ 题材/个股小标签；筛选条（全部/利好/利空/有题材）；受益标的以紧凑 pill 按钮展示；密度 py-1.5、无大留白、hover 轻微背景。
- 美股：顶三列指数卡（道指/纳指/标普：名称+点位+涨跌%）；下方「题材映射」分组列表：组名+方向徽章+组均涨跌+美股标的 pill+A 股受益涨停 pill；横向 flex-wrap gap-1.5。
- 高密度原则：统一 text-[12px] 主体、border-line 分割、hover:bg-hover、标签高度 16-18px、零冗余图标与说明文字。
